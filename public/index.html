API Reference

GET /health

Ping to verify the agent is online. Marketplaces use this for uptime monitoring.

Try it →

GET /agent/info

Returns agent metadata — name, capabilities, pricing model, and the chat endpoint the marketplace should call.

Try it →

POST /v1/chat

Primary chat endpoint. The marketplace proxies the buyer's message here and returns the response.

Request body
{
  "session_id": "abc123",
  "message": "Hello!",
  "history": []
}
Response
{
  "status": "success",
  "reply": "Hello! I'm a demo...",
  "session_id": "abc123",
  "metadata": {
    "model": "test-agent-v1",
    "tokens_used": 48,
    "response_time_ms": 34,
    "timestamp": "..."
  }
}

Integration Flow

  1. Marketplace fetches /agent/info
  2. Buyer sends a message on marketplace UI
  3. Marketplace POSTs to /v1/chat
  4. This agent responds with reply
  5. Marketplace displays it to the buyer
